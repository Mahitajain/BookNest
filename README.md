# BookNest

BookNest is my personal digital library — every book I've actually read, shelved as a bookshelf you can browse instead of a boring list. I built it to turn my own reading collection into something that feels like a real, physical library.

The idea came from an Instagram reel that showed a digital bookshelf, and I couldn't stop thinking about building my own version.
